One line (169 characters) — the phone battery's last text to the charger it waited for all day. The charger came home and charged everything else first, and the battery dies mid-word writing its own goodbye.

## The entry

> waited all day for you. you came home and charged the airpods, your vape, your watch — everything but me. now i'm at 1% writing my will in the notes app. tell mom i lov—

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes one line of plain text to `entry.txt` in the output directory (`/output` by default). Node 22, standard library only, no network.
